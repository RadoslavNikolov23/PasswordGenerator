# 🔐 Random Password Generator

A simple and interactive password generator built using **HTML**, **CSS**, and **TypeScript**. This tool allows users to create strong random passwords, copy them to the clipboard, and visually check their strength.

## 🚀 Features

- Generate random passwords (length 8–32)
- Show/hide generated password
- Copy password to clipboard
- Password strength indicator (color-coded)
- Reset functionality
- Info panel with password rules
